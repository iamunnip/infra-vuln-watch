# 12. Glossary

| Term | Meaning |
| --- | --- |
| CVE | A public identifier for one known vulnerability |
| CVSS | A 0 to 10 scoring system for severity |
| EPSS | The estimated chance of a CVE being exploited in the next 30 days |
| KEV | The CISA list of vulnerabilities known to have been exploited |
| CPE | A standard name for a product and version |
| CWE | A category of weakness, like "missing authorization" |
| NVD | The US National Vulnerability Database |
| C4 | Architecture views at system context, container, component and code levels |
| Container | A C4 application or data store boundary; here the CLI and inventory files |
| Component | A responsibility within a container, implemented here by Python modules |
| Deployment | One installed instance with a stable ID, environment, version and ownership |
| ADF | Atlassian Document Format used for Jira Cloud descriptions |
| Delivery receipt | A local record of an acknowledged Slack notification |
| arc42 | The 12-section structure used for this architecture description |
